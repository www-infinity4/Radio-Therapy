# Radio-Therapy

Radio-Therapy is an exploratory project for safe, educational radio/electronics experimentation (not medical radiotherapy).

## Safety and Scope

- This project does **not** support mind-reading, remote thought extraction, or behavior manipulation claims.
- Do not use radioactive materials, toxic heavy metals, or unsafe chemical/electrical setups.
- Follow established electrical safety practices and local laws/regulations.

## Scientific Baseline

Use reproducible measurements, peer-reviewed references, and standard RF/electronics methods when evaluating ideas in this repository.
